# Sources

Il-Kelma uses two corpora from the [MaCoCu project](https://macocu.eu/). Both were released through CLARIN.SI under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

- Bañón and colleagues, 2023. Maltese web corpus MaCoCu-mt 2.0. The spelling supplement uses word counts from paragraphs tagged as Maltese. [CLARIN.SI 11356/1803](https://hdl.handle.net/11356/1803)
- Bañón and colleagues, 2023. Maltese–English parallel corpus MaCoCu-mt-en 2.0. The sentence bank uses the aligned sentence file and keeps the English source domain for each pair. [CLARIN.SI 11356/1811](https://hdl.handle.net/11356/1811)

Korpus Malti remains the main spelling source. See [Maltese data and voices](MALTESE_DATA_AND_VOICES.md) for the other language resources.
